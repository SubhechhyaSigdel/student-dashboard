# StudentHub

A clean and responsive **Student Management System** built with React, TypeScript, and Tailwind CSS.

StudentHub allows administrators to manage students, track attendance, and manage application data through a simple dashboard interface.

## Features

* Dashboard with student and attendance overview
* Add, edit, view, and delete students
* Search students by name or email
* Filter students by course and status
* Track daily attendance
* Attendance pagination
* Light and dark mode
* Responsive design for mobile, tablet, and desktop
* Persistent data using browser `localStorage`
* Export student and attendance data as JSON

## Tech Stack

* React
* TypeScript
* React Router
* Tailwind CSS
* Vite
* LocalStorage
